# SPM-193 frontend test plan — coordinator notifications

Story [SPM-193](https://yvery.atlassian.net/browse/SPM-193), subtask SPM-268
(coordinator view of the Notifications page), on
`feature/SPM-193-coordinator-notifications`. Notification creation, wording,
assignment-scoped visibility and idempotency (AC1–AC8, AC10, AC12) are backend
work; see the backend repository's `docs/test-plans/spm-193.md`.

## Design reference

| Frame | Used for | URL |
| --- | --- | --- |
| `282:664` My Events | Updates button with unread count; placed after the stat chips in the Assigned Events header (the frame shows the attendee header only) | `/dashboard` |
| `282:1173` Notification card | Updates panel and inbox rows, unchanged from SPM-155 | panel; `/notifications` |

No new visuals: coordinators reuse the SPM-155 components, including the red
unread pill. The Coordinator Lead is out of scope and still has no inbox.

## Coverage

| Criterion | Automated evidence |
| --- | --- |
| AC11 / TC-14 | E2E: Updates on Assigned Events shows "3 unread" in the red pill and Mark all as read in the panel clears it; the inbox lists newest first with event, message and time, View marks one read (3 → 2), Mark all as read clears the rest. |
| AC9 / TC-11 | Unit: `notificationTargetHref` (EVENT_WORKSPACE → `/events/<id>`). E2E: Go to Event in the panel marks the notification read and opens `/events/81` in the coordinator's view. |
| AC9, AC10 / TC-03, TC-12 | Mocked: after reassignment the inbox shows the "Event assignment ended" notice but not the earlier notice for that event; its Go to Event opens `/events/82`, which shows "Event not available" (reassigned) and no details, and the notice stays listed, read. A notice hidden while the inbox is open is removed on Go to Event with "This event is no longer assigned to you." and no navigation. Enforcement is the backend's. |
| Access | Unit: `canViewPath`/`postLoginPath` allow attendees, organisers and coordinators only; the coordinator sidebar gains a Notifications tab that links to and highlights `/notifications`; the Lead has none. E2E: a signed-out coordinator returns to `/notifications` after login and sees the coordinator's empty-inbox text; the Lead is refused. |
| UI | E2E: mobile 390px header keeps a 44px Updates button and the panel fits with no horizontal scroll. Screenshots attached to the Playwright report. |
| Regression | The SPM-155 attendee and SPM-192 organiser journeys share the same mock module and still run. |
