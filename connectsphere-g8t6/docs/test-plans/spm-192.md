# SPM-192 frontend test plan — organiser notifications

Story [SPM-192](https://yvery.atlassian.net/browse/SPM-192), subtask SPM-258
(organiser view of the Notifications page), on
`feature/SPM-192-organiser-notifications`. Notification creation, wording and
owner-only visibility (AC1–AC6, AC8, AC10) are backend work; see the backend
repository's tests for SPM-192.

## Design reference

| Frame | Used for | URL |
| --- | --- | --- |

No new visuals: organisers reuse the SPM-155 components, including the red
unread pill.

| AC8 / TC-10, TC-11 | Mocked: a same-organisation organiser sees the owner's event under Organisation Events but none of the owner's notifications in the panel or inbox; the frontend sends only `limit`/`cursor`. Enforcement is the backend's. |
