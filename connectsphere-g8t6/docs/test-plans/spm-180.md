- Preserve main's global design tokens, warning color, shared focus utilities
  and elevation tokens. Calendar-specific variables belong to its CSS Module.

  labelled month bars, year indicators and configurable entity labels.

  enlarged the week view and obstructed month-bar clicks after integration.
- Retain the PR's shared queue loading and empty states.
- Add desktop/mobile browser regressions for visible keyboard focus (at least
  3:1 against the control background) and reassignment dialog elevation.
